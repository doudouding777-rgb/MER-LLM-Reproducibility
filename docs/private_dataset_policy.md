# Private Dataset Policy

Dataset-30k and Dataset-46k record-level contents are not publicly redistributed due to project data-release restrictions.

Publicly provided for these datasets:

- metadata
- counts
- schema
- lineage
- processing scripts where releasable
- sanitized configs/logs/results
- aggregate statistics

Do not upload complete JSON files, train/validation splits, caches, or intermediate files that can reconstruct Dataset-30k or Dataset-46k record contents.
