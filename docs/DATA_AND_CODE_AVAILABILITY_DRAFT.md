# Data and Code Availability Draft

The public reproducibility package for MER-LLM is prepared for release at a GitHub repository to be assigned after author approval. The repository includes Dataset-16k, preprocessing scripts, LoRA configuration files, sanitized training logs, evaluation statistics, paired McNemar analysis code, RAG sensitivity configuration/results, and engineering benchmark outputs.

Dataset-30k and Dataset-46k record-level contents are not publicly redistributed due to project data-release restrictions. Metadata, schema information, aggregate counts, processing scripts, configurations, logs, and aggregate results for these datasets are provided where release-safe.

Raw copyrighted source documents and converted full-text corpora are not redistributed. Question-bank files and anonymized expert scoring files require final author confirmation before public release.
